# Host notes
#
# Checked 2026-10-07 on Ubuntu 24.04 with Vivado/Vitis/PetaLinux 2023.2, from a
# fresh clone, up to (not including) the board steps (UART, run.tcl, SD/QSPI).
# The bare-metal installs (hello, menu, FSBL) took about a minute each; xsct did
# not hang.  PetaLinux 2023.2 needs two changes on Ubuntu 24.04 (not a validated
# host; the build warns about it):
#
# 1) Ubuntu 24.04 has glibc 2.39, newer than PetaLinux 2023.2's uninative 3.9,
#    so Yocto turns uninative off and pseudo fails.  After create_full.sh, add
#    to full/project-spec/meta-user/conf/petalinuxbsp.conf:
#
#      UNINATIVE_MAXGLIBCVERSION:forcevariable = "2.39"
#      UNINATIVE_VERSION:forcevariable = "4.4"
#      UNINATIVE_TARBALL = "${BUILD_ARCH}-nativesdk-libc-4.4.tar.xz"
#      UNINATIVE_URL = "https://downloads.yoctoproject.org/releases/uninative/4.4/"
#      UNINATIVE_CHECKSUM[x86_64] = "d81c54284be2bb886931fc87281d58177a2cd381cf99d1981f8923039a72a302"
#
# 2) If the repository sits in a directory with default ACLs (e.g. a shared
#    group directory), do_unpack fails with "cp: preserving permissions ...:
#    Invalid argument".  Remove the ACLs from the project and from petalinux/pkg
#    (the pacman-apps recipe links there):
#
#      setfacl -R -b -k full ../pkg        (from petalinux/)
#
# build.sh returns 0 even when petalinux-build fails: check its output.
# rpm2cpio (single package step) comes from the Ubuntu package rpm2cpio.
